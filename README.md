### <a name="introduction">🤖 Introduction</a>  <br/>
The Weather App allows users to search for real-time weather details of any city. Built with React.js and styled with modern CSS utilities, the app fetches live weather data from the OpenWeatherMap API. It provides temperature, humidity, wind speed, and weather conditions in a clean, responsive, and user-friendly interface.

### <a name="tech-stack">⚙️ Tech Stack</a>  <br/>
React.js
 → JavaScript library for building user interfaces with reusable components. <br/>
OpenWeatherMap API
 → Provides reliable weather data including temperature, humidity, and forecasts. <br/>
Tailwind CSS
 → Utility-first CSS framework for responsive and modern UI design.  <br/>

 ### <a name="features">🔋 Features</a>   <br/>

👉 Search City Weather: Enter a city name to view its current weather conditions.

👉 Weather Details: Displays temperature, humidity, wind speed, and condition description.

👉 Responsive UI: Fully responsive design for desktops, tablets, and mobiles.

👉 Error Handling: Notifies users if the city name is invalid or data cannot be fetched.

👉 Modern & Minimal Design: Clean layout with a focus on usability and accessibility.



### <a name="quick-start">🤸 Installation</a>
1. Clone the Repository
```
git clone https://github.com/VedantJ77/weather-app.git
cd weather-app
```

2. Install Dependencies
```Using npm
npm install
```
3. Set Up Environment Variables

Create a new file named .env.local in the root of your project and add the following:
```
VITE_WEATHER_API_KEY=your_openweathermap_api_key
Replace your_openweathermap_api_key with your actual OpenWeatherMap API key.
```
4. Run the Project
```
npm run dev
Open http://localhost:5173
```
